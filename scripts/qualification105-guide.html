Recovery and refusal are part of the result
The recovery test ends Java after two verified examples and resumes the same request. Completed child identities stay unchanged. A deliberately corrupted displayed value and a revised retained proof are both refused; neither publishes a new skill.
The supervisor checks capacity before starting and keeps the existing executable-workflow, native-goal and procedure limits. The browser presents the work; Java owns intent, sequencing, ownership, recovery and publication.


What this establishes
An owned procedure can qualify itself through a fixed, reviewable software test suite and retain reusable evidence. It can resume interrupted work and reject changed originals. The measured task uses authored Java/browser logic, with no content-generation calls or model-weight training. It does not prove arbitrary-task intelligence, broad numeric generalization or unlimited collection scaling.
