# Browser perception photo fixtures

Edition 022 includes two unmodified photographs from scikit-image v0.25.2 for
repeatable local browser checks. Neither photograph is generated by this app.

The local practice page animates these real photographs with explicitly synthetic
movement, resizing and hiding. It is a labelled development fixture, not footage
of an independently measured moving person or cup. Reference boxes were set after
pilot inspection; these are regression cases, not an untouched benchmark.

The person is used to test the generic category `person`. The app does not infer
the person's name or build a biometric identity database. The fictional profile
name on the practice page is page-supplied DOM text only.
