## Fresh acquisition

The user confirmed the same fixed webcam, mat, black target lighter and red comparison lighter. The red lighter is a similar-shaped, differently colored object; this is not an identical-lookalike challenge. Original images remain private and local. No tracking, model inference or source-dependent tuning runs during recording.

1. The user starts private preview, then clear reference. Save 34 approximately one-second samples with both objects visible and hands away. The causal donor is the first 24 reviewed clear frames; it must not share image bytes with evaluation.
2. The COVER cue asks the user to hide only the black lighter and confirm when covered. Keep the red lighter visible. After two further samples, automatically cue UNCOVER.
3. Uncover the same black lighter and slide it approximately one grid square left. Keep the red lighter still. Confirm the return with the hand away; capture another 24 samples and stop the camera automatically.
4. Preserve all original frames, actual camera timestamps, declarations, aborted attempts and limits. No splicing, retiming or marking an incomplete recording complete. Button cues are not visibility truth.

Review original pixels before predictions. Commit original hashes, attributed source-only target boxes, visibility intervals and competing-object boxes before comparison. Require source-visible displacement of at least half the initial target width somewhere in evaluation; separately report displacement on the first return frame. A stationary recording cannot qualify as a movement test. An otherwise valid long cover remains a test of refusal beyond the horizon, not a reason to change the method.
