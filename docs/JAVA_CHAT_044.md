## A retained skill is an executable procedure with checks

`Procedure044` resolves the actual Java registry by name/version, binds current sources, preserves retained material/force/constraint defaults, checks explicit requested overrides, and dispatches the registered native goal or workflow. Accepted Java planning/generation may continue after the interface closes. A new interface reconnects to the same project owner and task rather than silently starting another one. Browser/camera/canvas execution still needs that interface. A claimed uncertain surface action interrupts and needs explicit resume. Research retains completed source receipts when its browser disappears. The Java owner calls registered internal Java methods directly, with no privileged HTTP bypass or model-selected internal URL.

## Evidence and limits

A passing-looking model summary cannot complete a task. Java checks the current artifact version/content hash, exact original report assertions, actual child status and workflow audit. The same passing artifact receipt is explicitly recorded in the task's learning episode before a verified outcome is written. Read-only status queries and native actions without an artifact receipt retain the separate `completed-unverified` episode qualification. Native body movement, release and final frame must refer to the same settled run and tick.

These are operational ownership and continuity guarantees. They do not establish subjective awareness, general recursive improvement, new photographic identity recognition or trained language-model weights. Existing measured041 results and failed/unvalidated038 observations keep their original source-specific scope. This edition changes coordination; it does not replace the underlying physical, tracking, calibration or neural algorithms.

Validation and dated screenshots belong to the numbered edition's final evidence bundle. Development failures remain evidence, never passing results. Original private review projects, camera images, model weights and credentials are not publication assets.
