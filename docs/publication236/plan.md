## Qualification

Java rebuilds the original registration from the retained fit inputs and checks the original mesh identity. It projects the original and saved edit against a fresh view at the other supported elevation. The comparison accounts for the edit's collider-centre shift and rejects crop reuse, framing that would clip the projection, and a mesh outside its collider. The new image supplies evidence for the comparison. The camera and scale come from the original registration and the chosen elevation.

The check requires 86% silhouette overlap and a two-point gain over the original. A pass stores the full witness in the project, binds the source and edit hashes, and keeps a separate checked revision. The usual placement review binds this qualification and still requires approval, two matching contact runs and player clearance. Reopening evidence checks the saved witness bytes and both earlier scene revisions.

## Reproduce

```powershell
.\gradlew.bat :workspace-engine:installDist
$env:FRAYNIX_TEST_BLENDER = 'C:\Program Files\Blender Foundation\Blender 5.3\blender.exe'
node workspace-desktop/test/browser-views-integration.cjs build/mesh-qualification236 qualification
```

The optional Blender setting regenerates the fixture views and independently checks the exact exported GLB. Hosted portable jobs use checked-in fixtures for browser capture, Java qualification, restart, placement and replay. On macOS or Linux, use the shell Gradle wrapper and set the variable to the local Blender executable.
