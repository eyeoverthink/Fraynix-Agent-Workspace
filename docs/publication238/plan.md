# Recipients can branch a verified authored level

2026-11-24 · Edition 238

## Admission and lineage

Edition 237's portable workflow passed Windows, Linux, Intel Mac and Apple Silicon. The recipient editor admits its current authored-level archive format after a successful local replay. Java checks the exact replay digest before creating the local copy. The original destination is available in the archived format. The copy retains an immutable snapshot of the recipient replay alongside the archive reference and the exact final scene.

A deterministic root ID gives one local copy per archive. Each new revision binds the verified prior scene, the archived prop identity, and the original walking aisle. Opening the original evidence follows that root and reads the pinned replay. The separate viewer cache can regenerate independently.

## Edit and verification

The local editor changes the placed prop's X and Z coordinates and yaw. Preview checks the candidate against the floor, existing colliders, and aisle before storing the review. Approval binds the exact preview and source revision. After approval, Java executes two isolated native hit, miss, and aisle checks before retaining a new scene and its trial receipt. An intervening commit invalidates an older review. A failed or interrupted run leaves the verified scene available and the approval can be reopened.

The existing archive format and approval operate in the authoring project. The edited recipient revisions have their own local approval and evidence chain. Recipient geometry, collider authoring and sharing the edited branch evidence are future workflow additions.
