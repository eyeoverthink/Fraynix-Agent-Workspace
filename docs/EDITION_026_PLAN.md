Continue [edition025](../README-025.md) in the same private successor repository.

Implement a Java-owned `evidence-workflow-v1` supervisor over the existing
registered motion-data, native world-goal and creation procedures. This first
composition has a fixed, documented sequence; it is not a general task planner.

1. Freeze selected observation dataset/version/hash/mapping, data criteria,
   declared simulation parameters, target/disturbance, installed model name and
   requested outcome before execution.
2. Start an owned data goal; verify source reconstruction and its real report.
3. Start an owned native goal; verify actual prediction/control/disturbance and
   its real report. This simulation is separate from the recorded observations.
4. Java builds a source-preserving evidence bundle from original observations
   and actual recorded native forecasts/outcomes. No LLM invents evidence rows.
5. Start an owned creation goal with a frozen registered behavior contract.
   The local model creates the interactive explorer in the existing canvas.
6. Independently compare every displayed table cell to Java's original bundle
   and both29-point native SVG traces to reconstructed coordinates. Freeze
   viewBox0/0/800/300, x=40+720*t/1.5, y=260-220*x/max(1.8,target+0.2), and
   maximum coordinate error0.02 SVG units before live-model evaluation.
   Incorrect content drives bounded repair using actual observations. Only a
   completely verified workflow can retain a reusable workflow procedure.

Parent and child identities, stage intents, results and recovery are durable.
Stable child IDs reconcile a crash between child start and parent checkpoint.
Completed verified stages are reused; incomplete physics follows its existing
explicit new-attempt recovery. Cancellation stops owned work; stale effects,
changed sources/artifacts and detached child control cannot complete the parent.

One reserved workflow/shared goal at a time. Three ordered child goals; at most
three creation drafts across recovery; at most three explicit parent resumes;
1200seconds per attempt; existing child and storage budgets remain. This phase
accepts up to1000 original observation rows, with no hidden subsampling. Quality
flags are retained and shown separately from task completion. No new runtime
dependencies, model weights, cloud providers or LLM-weight training.

Keep the current design. Enter through Create & verify or a clearly routed chat
request. Show parent progress and actual stage evidence in the existing goal
card; retain whole-workflow procedures in the shared Skills library with fresh
dataset binding and explicitly changed physical conditions on reuse.

Acceptance includes actual data→physics→local generation→independent verification,
fresh-source/condition reuse, restart after completed physics without replay,
repair from a deliberately wrong table (labelled software control), cancellation,
foreign/stale receipts, source edits and ownership. Preserve first failures.
Run appropriate existing regressions and independent clean verification; publish
README026, real dated screenshots, exact examples, source hashes, offline guide,
Obsidian map, notes and main/readme-026 with direct GitHub verification.

The evidence establishes orchestration, source integrity and declared native
outcomes. It does not establish calibration to physical reality, general visual
understanding, model self-training or unrestricted autonomy.
