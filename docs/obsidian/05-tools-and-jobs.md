# Tools and jobs

Five compiled general handlers exist: world.inspect, memory.search, java.analyze, docs.generate and artifact.verify. Host grants and declared schemas govern calls. The operator Tools tab invokes these handlers and records results; Create retains its scene-specific loop.

Next integration: typed assistant/tool messages -> accumulated streamed calls -> host validation/grants -> existing dispatcher -> actual result messages -> continued inference. General Chat does not yet run that loop automatically.

Durable multi-worker scheduling, leases and persisted agent specifications remain planned. Completion must bind to the current task's real receipts and goal-specific validators.
