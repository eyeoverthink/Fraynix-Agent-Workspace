# Ask the workspace in everyday language

Ask Chat about a recorded object, compare two saved ramp setups, convert a file or build an offline click counter. Java binds each input and checks the result.

On Windows, the real local model proposed a motion report. After restart, the original proposal still required approval and the approved run used the original recorded source without a second model call.
