# One continuing Java agent

[[README-042|Edition042]] · [[docs/CONTINUING_JAVA_AGENT|Operation and recovery]] · [[docs/obsidian/continuing-agent.canvas|System map]]

One integrated interface renews a lease; its absence stops private host activity while native tasks can continue. Uncertain claimed actions require explicit Resume. Activity is computation, not useful learning or subjective emotion.
