# Agent factory plan and forecasts

The target is a persistent local factory for entities, components, data processors, artifacts, software recipes and agent specifications. Extend the existing runtime and dispatcher rather than creating another disconnected daemon.

Order: shared tool loop -> durable jobs/agent specs -> behavior-validated recipes and repair reuse -> artifact interoperability/recovery -> optional training/providers.

Planning scenarios assume focused 2–4 hour sessions: tool-loop pilot 2–4 sessions; durable jobs 4–8; first recipe 3–6 after foundation; bounded codec/recovery interoperability 2–5. These estimates require revision when scope or test evidence changes. Training effort is unresolved until data/hardware preflight.
