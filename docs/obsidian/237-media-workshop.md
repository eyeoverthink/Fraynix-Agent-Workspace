
# Media Workshop · Edition 229

The Media tab connects a trusted browser pick or local PNG to a Java-isolated sprite, a live layered draft, a checked editable recipe and a standalone playable level. The desktop and export use the same browser runtime. The project archive stores the checked source alongside the recipe. The playable export carries the derived sprite and layout.

The Windows tests used an original signal beacon and passed sprite alpha and color checks, draft repositioning, collision, platform landing, pickup, exit, restart, source refusal and independent offline play. The separate project reopened the level package and re-imported its sprite.

Build the multi-sprite library next. Keep an asset's source and derived forms linked, preserve the visual and collider distinction, and use a separate run or view as the witness.
