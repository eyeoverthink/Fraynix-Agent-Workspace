# Native body control and portable files

Edition 015 · October 30, 2026. Java owns real native grab/move/release with a bounded point constraint. The dynamic block moves through 240 Hz physics, retains collisions and preserves velocity at release. Per-axis impulse limit, reach/load/tick limits, measured reached/blocked outcomes, ownership fences, intent/receipt persistence and interrupted/cancelled operation handling are implemented. Native worlds now run on their own worker threads, including callback assertions.

Scene JSON import/clone validates the supported definition and creates fresh identities/provenance. Run JSON, native CSV, PNG and real silent WebM are exported with file/source/hash receipts. Video decodes/plays; native command replay checks final position. Choosing a scene file previews it before explicit import.

The first local-model trial mixed ownership IDs and was rejected/cancelled. Semantic agent tools now let the host bind actual observer/run/grip/fresh source. Native API fences remain. Host stages reject attempted repeat moves. The passing fixture checks a single +0.75 Y/+0.25 Z body motion, release and final native frame. These are development cases, not learned physical policies or model-weight training.

Next: general scene components and bounded mesh import, portable run-package remapping/replay, colliding navigation and separate physical policy evaluation/promotion. Existing app/layout/private data and original Studio stay separate.
