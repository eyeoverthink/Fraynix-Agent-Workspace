
# Sprite library and tile editor · Edition 230

The Media tab now uses checked source records across more than one level. Draw terrain with the tile brush, drag sprites on the canvas, and edit one collision rectangle per solid tile or prop. Saving verifies the original source and derived pixels, and standalone HTML embeds the same runtime as the desktop preview.

The Windows tests exercised two scenes, four retained tiles and edited prop and tile collisions. The full course passed before and after desktop restart and offline. Reopening produced the same HTML digest. Import restored both sprites in a separate project, and altered evidence was refused.

The next bridge is between these reusable source records and Spatial's registered-view 3D reconstruction with a separate mesh and collider.
