# Native world and observer

Edition 014 · October 30, 2026. The user clarified that the engine and native logic should own the experience: no video transformer is required. Java implements pose, bounded movement, sampled actual-box visibility, inspection, source/run/tick packets, receipts and persistent history. The existing Three renderer captures actual PNGs. Manual workflow needs no model inference; the optional local-model adapter uses those same tools.

The first local-model trial exhausted 16 steps on Unknown observer record. Narrowing agent open to sceneId removed the ambiguous optional observer selector. A second trial repeated movement after capture and was cancelled; authoritative progress and a finish-only completed stage now prevent that. The independent fixture checks exact 1 m movement, real Block inspection and final frame/source hashes. Preserve the failed trial separately from the passing result.

Free camera is not physical locomotion/grasping. Sampled native geometry is not general vision. Saved observations are evidence, not proof of learned improvement. Next: a real physical actuator with limits and postcondition checks, colliding navigation, then separate tick-aligned training/evaluation and rollback. Keep the current app/repository and original Studio separate.
