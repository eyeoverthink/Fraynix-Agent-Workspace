# Development before the fresh-source freeze

The first focused attempt ran nine tests and failed two pixel-level recovery assertions. The original failure log/XML and development trace are retained. The previous appearance engine required more adjacent observations than the initial trajectory envelope allowed. The initial new envelope used a quadratic coefficient of 0.0015 and expired on uncertainty before the twelve-frame age limit. Before any fresh image access, the new coefficient was fixed at 0.0005 (an explicit 0.001 acceleration allowance), while the original appearance checks, scoring, defaults and original baseline were unchanged. Stale invalid target paths no longer create new rival assignments. Incomplete appearance confirmation is now explained explicitly.

The second focused attempt passed all nine checks. A further capacity-overflow check and an overflow witness were then added before freeze; the final broader suite must run these final sources. No fresh outcome informed these development changes. These image-plane bounds are uncalibrated assumptions, not a probability guarantee. Restored boxes and predictions never extend the baseline anchor. Original exposed144 cases without a measured pre-loss path remain refused.
