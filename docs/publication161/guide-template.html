Try the small-object path

  1. Open Spatial → Single-object motion.
  2. Create the labelled 5 cm test scene or choose a compatible imported scene.
  3. Enter target X/Z and the declared coordinate allowance; Check route, then Run bounded move.
  4. Inspect report & accept verified result. Java replays the original motion and checks actual visible report controls before accepting a revision.
  5. Scrub time, position and speed. Recheck originals after a restart or before continuing.

One upright 5–15 cm box, 20–200 g, on a flat floor. No physical lighter movement, automatic camera authority or new chat route. The existing recorded-motion evaluator remains available.

Blender and the next phases

Blender can help with optional asset authoring, rendering and labelled synthetic scenes. It also uses Bullet for rigid-body simulation, so agreement is not independent proof of real physics. Java keeps task ownership, state and verification. No Blender dependency or copied Blender implementation is introduced here.

Next: independently labelled physical episodes, qualified small-object image/world binding, then durable chat and skill integration. Optional scene exchange follows stable-ID/unit/transform round-trip tests.
