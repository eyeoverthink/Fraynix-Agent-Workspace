What is verified

Conditional plane mapping supports explicit simulation markers. It does not establish live object pose, calibrated coverage probability, object height/contact or hardware authority. The recorded041 source is exposed; generated references are labelled.

How to use it

  1. Open Spatial → Measured mat alignment → Recorded plane → checked simulation action.
  2. Load a saved measured reference and select a separate destination world.
  3. Choose a reference marker, a withheld printed-grid landmark and an explicit return marker. The latter is lifted and returned to its starting pose by the inherited two-body controller.
  4. Review budgets, check the route and prepare the chat request.
  5. Send the request. Use “review before action” for a checkpoint; Resume rechecks the same sources and owned goal.
  6. Inspect actual outcome, bounds, original checks and saved procedure.

Existing native control requires boxes at least0.2m wide; closely spaced mat references do not override collision checks. Larger planes can accept two measured markers through the typed workflow input.
