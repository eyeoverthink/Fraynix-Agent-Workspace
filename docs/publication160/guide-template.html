What is verified

One exposed camera episode and two labelled generated sequences. Conditional bounds are not calibrated probabilities. Missing observations stay unknown. No new live-pose or physical-action authority.

How to use it

  1. Open Spatial → Independent motion checks.
  2. Load completed recorded movement trials with independent endpoint labels; choose one to four distinct episodes.
  3. Review the declared allowances, then Evaluate original footage.
  4. Resume interrupted reconstruction against the same frozen inputs.
  5. Open and verify report. Inspect every fixed pair, the error chart and source identities.
  6. Recheck original evidence after completion; edited sources or reports are refused.

A new empty project contains no private camera episodes. This view does not start the webcam, change defaults or move an object. Next: separate physical validation and a smaller native control domain.
