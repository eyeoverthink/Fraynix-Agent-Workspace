# Edition 185 implementation plan

Choose an interrupted Fray chain by its durable review ID. The Workbench lists only reviews with a saved first-stage receipt and presents the exact input and verified intermediate with their units. Open a selected review and recheck its saved first-stage observations before running the second stage.

The local acceptance run pauses three chains across both recipes, creates one unapproved review, stops the isolated desktop and Java process tree, and reopens the same project. It resumes the middle chain first and verifies that pending sibling files stay byte-identical. It separately attempts a wrong-unit handoff and a wrong-value handoff with the correct unit.

The execution timeline records two measurements for each recovered job. The first starts with the verified preview fetch and ends when Java accepts the rebuilt first stage. The second starts after that acceptance and ends when Java saves the second-stage proof. App startup, selecting a chain, and opening the saved artifact are outside those timings. The report also records the elapsed time to bring up the three-item chooser. These are local samples from one Windows machine.
