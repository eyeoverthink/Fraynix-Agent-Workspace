# Operational self-model and persistent object knowledge

Edition039 adds an actual local knowledge path to the existing visual workspace. Java owns object associations, frozen research definitions, progress, cancellation generations and cached-source checksums. The desktop supplies its real tool catalog and runs one separate, unprivileged browser worker. The local model chooses among the tools registered for its current task stage.

Open **Knowledge & tools** beside Your agent. Search for a capability, or expand **Keep a selected tabletop observation** after selecting a recorded Tabletop run. A human label/category is required. A new observation can be explicitly associated with an existing object in the same native world/body. Rebinding the same recorded run reuses its UUID. Selecting an object persists the choice for chat and restart.

The object retains the original run, body, world, tracker-code, geometry and image hashes. These links establish provenance. They do not prove that two recordings depict the same physical item. A category edit increments the identity revision; already-running research keeps its original category and becomes completed-stale if that revision changes.

**Research this human category** starts a text search in a separate browser. Google is attempted first, then Bing if no result plan is obtained. At most three result pages are read, each bounded to12,000 characters and12 reference-image URLs. One worker runs at a time, with120 seconds per attempt and at most three interrupted/resumed attempts. Human verification, consent, timeouts and failed source reads are retained. There is no challenge bypass. If all sources fail, the job fails explicitly. Explicit URL ingestion is labelled provided-urls and is never reported as successful search.

The worker does not share the visible browser, camera, page privileges or cookies. It has no Node access, microphone/camera permissions, downloads or popup authority. External requests obey the app's offline mode. Production research rejects local/private address destinations. Reference-image URLs and alt text are retained as data, including potentially irrelevant site graphics; image pixels are neither downloaded for matching nor compared with the camera target. Only the human category enters the search query. Original private camera images are never uploaded by this workflow.

Completed sources and failed steps survive interruption. **Resume interrupted research** continues from the next unacknowledged page and preserves the cached prefix. **Cancel research** increments the generation so late callbacks cannot enter the job. A corrupt source or journal is refused while originals remain in place. Metadata is atomically replaced under a file lock; source documents are checked by full-document and text hashes. Limits are64 objects,64 research jobs,32 observation bindings per object and256 cached documents; reaching a limit stops new writes rather than pruning history.

**Open cached-source report** creates a real saved artifact. The host checks the exact object UUID, job UUID and source count in the actual canvas. Cached citations open local escaped source text. The separate **Open actual source in browser** control explicitly navigates the visible browser to the live reference. Untrusted source text cannot install tools or change native physical state.

The five new typed model tools are `self.read`, `object.read`, `object.research`, `object.wait` and `object.report`. Object tools take no model-supplied IDs, URLs, measurements or success flags: the host pins the user's selected object. Every planning request, including older task routes, receives a compact fresh operational self-context. The model can inspect declared tools, actual host state, available local models, retained objects/jobs and recent execution receipts. Network permission and a dated successful fetch are separate facts. Host freshness expires after10 seconds; startup does not restore an old capability registration as current.

This is operational self-knowledge and persistent source-linked memory. It does not establish subjective awareness, visual recognition, learned product identity, neural-weight changes or general intelligence. Existing edition038 physical displacement and uncertainty remain unvalidated. Native simulation, observation, human labels and web hypotheses remain separate authorities.

The last command uses an installed gpt-oss:20b and actual public internet access, so provider blocking is an observable failure rather than a fixture pass.
